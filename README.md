# 🚀 Code Evolution Visualizer

Analyze any GitHub repository and visualize its development history through interactive analytics.

## 📌 Features

- 📊 Repository Analytics
- 📈 Commit Timeline Chart
- 👥 Contributors Count
- 👤 Contributors List
- 📝 Recent Commits
- 🔥 Hotspot Analysis
- 📂 File Change Analysis
- 🔗 Analyze any public GitHub repository

## 🛠 Tech Stack

### Frontend
- React.js
- Tailwind CSS
- Axios
- Recharts

### Backend
- Node.js
- Express.js
- Simple-Git

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/your-username/code-evolution-visualizer.git
```

### Backend

```bash
cd server
npm install
npm run dev
```

### Frontend

```bash
cd client
npm install
npm run dev
```
